# 兔兔数学 🐰

面向低年级的简体中文数学练习应用。复用 [Bunny Math](https://github.com/BinaryDevil/bunny-math) 的兔子 SVG、配色、卡片、按钮、贴纸、音效和庆祝效果，加入中文低年级练习与三种计算方法。全部在浏览器运行，无需账号、后端或 AI 接口。

![横屏平板首页](./screenshots/home-tablet.jpg)

## 功能

- 综合练习：10 以内、20 以内不进退位、20 以内进退位三个等级；每轮 15 或 20 题。
- 数字填答、单项选择、补全算式、比较大小和图片故事五类综合题。
- 凑十法、平十法、破十法：3 步示例、十格框、拆数图、步骤填空与独立计算。
- 首次答题、订正与使用帮助分别记录；结果页可回顾每一道题、查看图解或练习最多 5 道错题。
- 页面右下角提供卡通字体署名「Designed by 杨慕筱」，中文字体随站点打包。
- 完成奖励、星星和贴纸册；本机记住音效设置、题目和题内步骤；默认静音。
- A4 练习纸、专项步骤题与可选的独立答案页；打印同一轮题目时保持题目一致。
- 手机和平板响应式布局，支持虚拟键盘、实体数字键、退格与 Enter；支持减少动态效果偏好。

普通题答错后可重试一次，再错会展示答案；步骤题每一步有同样的重试机制。使用过帮助会单独标记，首次成绩不会因订正而改写。星星：完成 1 星，首次正确率达到 70% 为 2 星、90% 为 3 星。

## 三种方法

| 方法 | 关键 | 示例 |
| --- | --- | --- |
| 凑十法 | 拆加数，先凑成十 | 8+5：5=2+3；8+2=10；10+3=13 |
| 平十法 | 拆减数，先减到十 | 13−6：6=3+3；13−3=10；10−3=7 |
| 破十法 | 拆被减数，先从十里减 | 13−6：13=10+3；10−6=4；4+3=7 |

每次生成新题；链接加上 `?seed=123` 可复现同一配置下的题目，`seed=0` 也有效。方法专项的 15 题包含 6 道步骤题和 9 道结果题；20 题包含 8 道步骤题和 12 道结果题。一道步骤题内的多个空格只计一道题。

## 本地运行

建议 Node.js 24 LTS：

```sh
npm ci
npm run dev
```

验证及生产构建：

```sh
npm test
npm run build
npm run preview
```

打开终端显示的地址。产物位于 `dist/`，采用相对资源路径，可部署到任意 GitHub Pages 仓库子路径。

## 代码结构

- `src/cn/math.ts`：低年级候选集、种子出题、配额、三种方法的解释数据。
- `src/cn/state.ts`：作答、重试、步骤推进、计分、本机存储及防重复奖励。
- `src/cn/App.tsx`：中文首页、答题、结果、贴纸和练习流程。
- `src/cn/Lesson.tsx`：原生对话框、十格框、拆分图和分步讲解。
- `src/cn/Print.tsx`、`style.css`：打印和中文响应式样式。
- `src/cn/math.test.ts`：新增生成器、讲解、恢复及计分测试。
- `src/components/Bunny.tsx`、`src/lib/sound.ts`、`celebrate.ts`：复用原版插图与互动效果。
- 原版其他组件、生成器与测试保留，入口 `src/main.tsx` 使用中文应用。

## 数据与使用范围

应用不上传作答数据，不加入统计 SDK。设置、最近结果、进行中的练习和贴纸保存在当前浏览器的 `localStorage` 中；清理浏览器数据会删除它们。存储被禁用时仍可练习，但不会记住进度。完整离线缓存、跨设备同步和中文朗读不在首版范围内。
